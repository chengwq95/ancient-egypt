# 古埃及文明全景 · Ancient Egypt

一个中英双语的古埃及科普长页面。单文件 HTML，除了一个图片文件夹和两个 Google Fonts 之外没有任何依赖。

## 内容

17 个章节：九柱神世系、众神图鉴（18 位，可分类筛选与搜索）、神祇辨识指南、法老、金字塔、科技与建筑工艺、日常生活与社会、木乃伊与来世、象形文字、神庙、尼罗河地图、数字与冷知识、埃及历史（14 章卷轴）、奥西里斯传说（10 章卷轴）、术语表（37 条）、常见误解问答、关于本页。

## 特性

- **中英双语**，一键切换，全站内容双语对照
- **深浅两套主题**，夜间星空 / 白昼沙尘与飞鸟
- **纸莎草卷轴**：历史与神话做成可拖拽、可滚动展开的卷轴
- **古地图**：手绘风格的尼罗河遗址地图，按类型筛选
- **生成式背景音乐**：Web Audio 实时合成，模拟弓形竖琴、奈伊笛、叉铃、框鼓
- 按需渲染、无障碍支持（键盘操作、焦点样式、ARIA）

## 声明

- **页面上所有图片均由 AI 生成**，用于营造氛围，不能作为文物的视觉依据。
- 内容为科普性整理，非学术出版物。仅见于希腊罗马作者的说法已在文中标注出处，学界仍有争论之处已并列呈现。
- 背景音乐是**拟古而非复原**——古埃及没有留下任何乐谱。
- 详见页面底部的「关于本页」一节。

